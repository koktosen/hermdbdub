Set up your wall

This is a display for the things you'd otherwise check on your phone: every calendar you have in one place, the weather, markets, headlines, and a morning brief your assistant writes and reads out loud. It runs on a small computer behind your TV and gets everything from this computer, the one serving this page.

How it works, honestly: this computer collects the data and keeps it on your own network. The screen just shows a web page from here. Nothing is sent to anyone else. If you want the wall somewhere other than home, it needs a way to reach this computer — that's what the "tailnet" step is for.

1 · The small computer

Which board will sit behind the TV? This decides which system image to flash and a few settings.

Pi 1 and 2 have no Wi-Fi built in — plan on a cable or a USB Wi-Fi adapter for those.

2 · Network

So the board can get online the first time it boots, without a keyboard.

Want the wall to work away from home, or on a different network than this computer? Then both need to be on a private network of your own — a tailnet. If you don't know what that is, choose "same network" for now; you can add it later.

5 · Your calendars

This is the one thing nobody can fetch for you: each calendar has a private link that only you can see when logged in. Paste each one here. It is tested the moment you paste it.

Where to find the link
  • Google Calendar — Settings → pick the calendar → "Secret address in iCal format". One per calendar.
  • Proton Calendar — the calendar's menu → Share → Share via link → create. Copy the link.
  • iCloud — on icloud.com or the Mac Calendar app, share the calendar as a Public Calendar; copy the webcal:// link.
  • Outlook / Office 365 — Settings → Calendar → Shared calendars → Publish → copy the ICS link.
  • Nextcloud, Fastmail, others — any "subscribe", "ICS" or "webcal" link works.

Keep these private: anyone with the link can read that calendar. They are stored only on this computer.
